燃气管线泄漏检测与隔离协调

使用 JSON API 创建泄漏事件、登记巡检或传感记录，并完成核验、隔离、抢修、试压与恢复。隔离任务与阀门指令绑定：同一管段未结束前只保留一套有效顺序，重复提交会看到占用与差异；指令有唯一代号，回执按修订号判重，更新指令后旧回执失效；网络恢复后对账未完成指令，无法确认的转人工处理。
